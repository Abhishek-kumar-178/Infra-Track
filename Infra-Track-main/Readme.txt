InfraTrack

InfraTrack is a web application made for civil engineering companies to manage
their material procurement process. It allows users to create orders, collect
quotations from vendors, and get them approved by the concerned authority.

This project was built as part of an academic assignment.

Features:
- Create and manage purchase orders
- Add and compare quotations from different vendors
- Approval system based on user roles
- Different login access for different users (admin, manager, etc.)

Tech Stack:
- Frontend: React (TypeScript)
- Backend: Java Spring Boot
- Database: MySQL
